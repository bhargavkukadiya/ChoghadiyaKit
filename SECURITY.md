# Security Policy

## Supported Versions

We actively maintain and support security updates for the following versions of **ChoghadiyaKit**:

| Version | Supported          |
| :---    | :---:              |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

The security of **ChoghadiyaKit** and applications that depend on it is taken seriously.

If you believe you have found a security vulnerability:

1. **Do not disclose the issue publicly** (e.g. do not open a public GitHub issue).
2. Please report the vulnerability privately via **GitHub Security Advisories** on the repository or email the maintainer at `30554745+bhargavkukadiya@users.noreply.github.com`.
3. Include detailed reproduction steps, sample Swift code, and the impact of the issue.

### Response Timeline

- **Initial Acknowledgment:** Within 48 hours.
- **Triage & Status Update:** Within 5 business days.
- **Fix Release:** Vulnerabilities will be addressed in a patch release and accompanied by a security advisory once resolved.
